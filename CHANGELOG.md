# Changelog

## 0.1.0 - 2026-10-06

- Initial public release.
- Non-blocking 11-byte WIT frame parser with checksum and resync.
- Acceleration, gyro, Euler angle, magnetometer and quaternion decode.
- HardwareSerial / SoftwareSerial-compatible API.
- Software zero and arbitrary current-angle remapping.
- WIT register write/read helpers.
- Robot configuration helpers and diagnostics.
- Arduino examples and CI.
